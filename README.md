# VTU AI LAB MANUAL

This folder contains implementations, explanations, and runnable Python programs for BAD402 (VTU) AI lab exercises.

Tasks included:

1. Depth First Search (DFS) on the Water Jug Problem — `dfs_water_jug.py` (implemented)
2. Best-First Search on Missionaries-Cannibals Problem — `best_first_missionaries.py` (implemented)
3. A* Search algorithm — `astar.py` (implemented)
4. AO* Search algorithm — `ao_star.py` (implemented)
5. 8-Queens Problem solver — `eight_queens.py` (implemented)
6. TSP using heuristic approach (Nearest Neighbor) — `tsp_heuristic.py` (implemented)
7. Problem solving strategies: Forward or Backward Chaining — `chaining.py` (implemented)
8. Resolution principle on FOPL — `resolution_fopl.py` (implemented)
9. Tic-Tac-Toe game — `tictactoe.py` (implemented)

How to run
----------

Install Python 3.8+ and (optionally) `numpy` for some demos. From this folder run:

```powershell
python dfs_water_jug.py
python best_first_missionaries.py
python astar.py
python eight_queens.py
python tsp_heuristic.py
python tictactoe.py
```
